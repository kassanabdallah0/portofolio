# Kassan Abdallah - DevOps Engineer Portfolio

Modern bilingual portfolio built with React, TypeScript, Vite, and Tailwind CSS.

## Live

- GitHub Pages: `https://kassanabdallah0.github.io/portofolio/`

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Radix UI / shadcn components

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Deployment (GitHub Pages)

This repo uses GitHub Actions workflow:

- `.github/workflows/deploy.yml`

And Vite base path for this repository:

- `base: '/portofolio/'` in `vite.config.ts`
